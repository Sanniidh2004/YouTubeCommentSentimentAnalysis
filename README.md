### Project Description
This project is a YouTube comment section Sentiment Analysis using HTML and Python. It can divide sentiments into Positive, Neutral or Negative.

- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Sentiment Analysis: TextBlob
- API: YouTube Data API v3
- Server: Uvicorn
- Data Format: JSON

### Files Included
- index.html - Webpage structure and layout
- main.py – Backend code and routing
